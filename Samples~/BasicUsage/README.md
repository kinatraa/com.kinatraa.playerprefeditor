# Basic Usage

`sample-playerprefs.json` is a small PlayerPrefs document in the package's JSON format.

1. Open **Tools ▸ kinatraa ▸ Player Pref Editor**.
2. Click **Import** and pick `sample-playerprefs.json`. The dialog shows how many keys will be added, changed or left unchanged.
3. Click **Import** to apply. The four keys appear in the list with their type badges.
4. Edit a value, then **Save**, **Revert**, **Copy JSON** or **Delete** it. Use **Export** to write everything back to a file.
