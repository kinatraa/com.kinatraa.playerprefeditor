# Basic Usage

`sample-playerprefs.json` is a small PlayerPrefs document in the package's JSON format.

1. Open **Tools ▸ kinatraa ▸ Player Pref Editor**.
2. Click **Import ▾ From File…** and pick `sample-playerprefs.json`, or drop the file on the window. The preview lists each key as added, changed or unchanged.
3. Click **Import N Changes**. The keys appear in the list with their type badges. **Undo** removes them again.
4. Select `settings_json` to edit its JSON content formatted. Edit a value, then **Save**, **Revert**, **Copy JSON** or **Delete** it. Use **Export ▾** to write everything back to a file.
